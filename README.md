# FitFlow Redesign

FitFlow is a cross-platform fitness application redesign that provides AI-powered workout recommendations, nutrition tracking, social community features, and real-time notifications.

## Technology Stack

- Frontend: React Native
- Backend: Node.js + Express
- Cloud / Real-Time Services: Firebase
- Authentication: Firebase Authentication
- On-Device AI: TensorFlow Lite
- Computer Vision: ML Kit
- Advanced AI: Cloud AI Services
- API Communication: REST APIs
